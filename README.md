# Tito AI Video Generating

AI-powered video generation platform that creates videos from text prompts.

## Features

- User Authentication
- AI Video Generation
- Video History
- User Dashboard
- Cloud Storage
- Subscription Ready

## Tech Stack

- Next.js
- Tailwind CSS
- Supabase
- Vercel
